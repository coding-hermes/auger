# AUG-111 verification artifact

## Scope and safety boundary

The shipped surface is `python3 auger.py ns gc --prefix auger-pytest-`. The exact literal prefix is
required. The implementation refuses every other prefix, refuses a sweep while the shared pytest
substrate lock is held, preserves fresh `auger-pytest-<conftest-session-tag>-...` directories, and
uses the existing confirmed namespace DELETE helper before removing the exact local directory.

No live operator cleanup was run in this worker session. The live figures below are the values
recorded in the AUG-111 board premise, not a new live claim from this verification:

- `grep -c auger-pytest ~/duckbrain/duckbrain.config.json`: 15,492
- config size: 1,199,258 bytes
- namespace directory census: 645 directories, 1,177,896 KB reported by the row

## Deterministic fixture reproduction

The fixture probe used the real `garbage_collect_namespaces` implementation with a fake HTTP
substrate, three stale prefixed mappings/directories, one fresh concurrent-session-tag namespace,
and two unrelated mappings/directories. It captured the same before/after surfaces requested for
the live reproduction. The output below is copied from the executed probe; the temporary root was
`/var/tmp/hermes-scratch/aug111-fixture-zvhhh_oh`.

after.grep_count=2

The fixture's `grep` count is eight before and two after because each pretty-printed mapping carries
the namespace name in both the mapping key and path. The unrelated mapping rows were compared as
serialized bytes and remained unchanged; their directories remained present. The live namespace
uses the current conftest session-tag family and was not sent a DELETE request.

## Killed-session evidence

`test_namespace_gc_reaps_sigkilled_session_but_preserves_concurrent_tag` starts a child fixture
that writes the registry and six namespace directories, sends it `SIGKILL`, then runs the sweep.
The test asserts the killed residue is reported as `removed 3`, exactly three DELETE names are sent,
the current conftest-tagged concurrent namespace remains, and unrelated mappings remain.

## Reproduction procedure for an authorized live probe

Run only against an explicitly authorized DuckBrain instance and the exact supported prefix:

```bash
grep -c auger-pytest ~/duckbrain/duckbrain.config.json
wc -c < ~/duckbrain/duckbrain.config.json
find ~/duckbrain/namespaces -maxdepth 1 -type d -name 'auger-pytest-*' -printf '%f\n' | sort | tee /tmp/auger-pytest-namespaces.before
while IFS= read -r ns; do du -sb -- "$HOME/duckbrain/namespaces/$ns"; done < /tmp/auger-pytest-namespaces.before
python3 auger.py ns gc --prefix auger-pytest-
grep -c auger-pytest ~/duckbrain/duckbrain.config.json
wc -c < ~/duckbrain/duckbrain.config.json
find ~/duckbrain/namespaces -maxdepth 1 -type d -name 'auger-pytest-*' -printf '%f\n' | sort | tee /tmp/auger-pytest-namespaces.after
while IFS= read -r ns; do du -sb -- "$HOME/duckbrain/namespaces/$ns"; done < /tmp/auger-pytest-namespaces.after
```

The live command's count-based report and the two independent read-backs are required before
claiming live cleanup.
